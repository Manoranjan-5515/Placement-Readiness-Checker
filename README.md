# Smart Placement Readiness Checker

A beginner-friendly Python and Streamlit web application that helps students review their placement preparation.

## Features
- Self-assessment for CGPA, aptitude, coding, communication, and interview confidence
- Resume, project, mock-interview, and practical-experience checklist
- Readiness score out of 100
- Skill-by-skill breakdown
- Personalized suggestions based on lower-scoring areas

## Technology
- Python
- Streamlit

## Run locally

1. Install Python 3.10 or newer.
2. Open a terminal in this project folder.
3. (Recommended) Create and activate a virtual environment.
4. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Start the app:

   ```bash
   streamlit run app.py
   ```

6. Open the local URL printed in the terminal (usually `http://localhost:8501`).

## Upload to GitHub

1. Sign in to GitHub and create a new public repository named `smart-placement-readiness-checker`.
2. Upload `app.py`, `requirements.txt`, and `README.md` (or push the folder using Git).
3. Open the repository page and copy its URL.
4. Paste that repository URL into the YBI Foundation assignment's **Add Link** field.

## Important
This is a rule-based self-assessment project for learning purposes. It does not use a trained machine-learning model and does not guarantee job placement. Update the project according to the exact instructions from your live class before submitting.
